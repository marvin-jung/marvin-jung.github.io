SEED 디자인 시스템 분석

당근 SEED의 토큰 아키텍처를, 문서를 읽는 데 그치지 않고 브라우저에서 직접 실측한 564개 CSS 변수로 해부합니다.

Design System Analysis 2026. 8. 1. · 8분 읽기
$dimension.x4 $color.fg.brand $spacing-x.global-gutter

어떻게 분석했나

SEED는 당근(Daangn)의 공식 디자인 시스템입니다. "Seed to Root, Root to Daangn" — 모든 당근 제품이 공유하는 최소 단위의 뿌리를 지향합니다. 이 글은 문서를 요약한 것이 아니라, 실제 사이트를 브라우저에서 열고 getComputedStyle과 스타일시트 순회로 런타임에 노출된 564개의 --seed-* CSS 변수를 전수 추출해서 쓴 글입니다. 아래 나오는 모든 hex 값과 수치는 그 실측값입니다.

2계층 토큰 구조

SEED 토큰의 핵심 철학은 "값이 아니라 의미로 관리한다"입니다. 구조는 명시적인 2단계입니다. Scale Token은 무한한 raw 값 중 실제로 쓸 값을 제한하고 이름을 붙입니다($dimension.x4 = 16px). Semantic Token은 Scale을 조합해 의도를 표현합니다($spacing-x.global-gutter → x4). 같은 #FF6600이라도 브랜드 배경과 브랜드 텍스트는 별도 토큰입니다 — 의미가 다르면 따로 업데이트할 수 있어야 하기 때문입니다.

Semantic Token $spacing-x.between-chips $color.fg.brand $spacing-x.global-gutter
Scale Token $dimension.x2 $color.palette.carrot-600 $dimension.x4
Raw Values 8px #FF6600 16px

역할 기반 색상 — bg / fg / stroke

색상은 세 가지 역할로 나뉩니다: bg(배경, 43개), fg(전경·텍스트, 16개), stroke(테두리, 16개). 각 역할은 의미 카테고리(brand, neutral, critical, informative, positive, warning, magic, disabled, layer)와 강도 변형(solid/weak, -pressed, -contrast, -muted, -subtle)의 조합입니다. 눌림 상태(-pressed)까지 토큰으로 정의한 꼼꼼함이 눈에 띕니다.

토큰실측값용도
color-bg-brand-solid#f60당근 브랜드 오렌지
color-bg-brand-solid-pressed#e14d00브랜드 버튼 눌림
color-bg-critical-solid#fa342c오류·파괴적 동작
color-bg-informative-solid#217cf9정보
color-fg-positive#079171긍정·성공
color-bg-warning-solid#fbdc65주의
color-fg-neutral#1a1c20기본 텍스트
color-stroke-neutral-weak#dcdee3약한 구분선

여기에 역할로 표현하기 어려운 예외를 위한 팔레트 색상 94개(각 색 100~1000 명도 스케일, 예: carrot-100 #fff2ec → carrot-1000 #471601)가 별도로 존재하고, 매너온도용 color-manner-* 20개, 배너용 파스텔 10개처럼 범용 시스템 위에 서비스 고유 토큰을 얹는 확장 패턴도 보입니다. 접근성 기준으로 WCAG가 아닌 APCA 명도 대비를 채택한 것이 차별점입니다.

유동 타이포그래피

14단계 스케일(t1~t14, 11px~48px)의 각 사이즈는 고정값이 아니라 clamp() 기반 유동형입니다. 실측된 t1의 정의를 보면:

--seed-font-size-t1: clamp(calc(11px * .8), calc(.6875rem * 1), calc(11px * 1.5));
--seed-font-size-t1-static: 11px; /* 고정이 필요할 때 */

사용자의 폰트 배율 설정에 0.8~1.5배 범위로 반응합니다. 접근성이 스케일 설계 단계부터 들어가 있는 셈입니다. 폰트 두께는 regular 400 / medium 500 / bold 700 세 단계, 폰트 스택은 OS 시스템 폰트 우선입니다.

멀티플랫폼 배포

내비게이션에 React와 Lynx(크로스플랫폼 프레임워크) 구현이 별도로 나뉘어 있고, Breeze 프로젝트, Migration 가이드, LLMs.txt를 제공하는 AI & Tools 섹션까지 갖추고 있습니다. 토큰을 단일 소스로 두고 여러 런타임에 배포하는 구조로, 약 50개 컴포넌트가 문서화되어 있습니다.

종합 평가

SEED는 (1) 의미 중심 2계층 토큰, (2) 역할+팔레트 이원화 색상, (3) APCA 접근성, (4) clamp 기반 유동 타이포, (5) 멀티 런타임 배포가 핵심인 성숙한 프로덕션 디자인 시스템입니다. 실측하면서 가장 인상적이었던 건 거창한 것이 아니라 pressed 상태, 모션 duration 6단계 같은 작은 결정들이 전부 토큰으로 봉인되어 있다는 점이었습니다. 일관성은 그렇게 만들어집니다. 이 블로그와 포트폴리오 자체가 그 실측 토큰으로 지어졌습니다.
