정석 코스: After Effects + Bodymovin 완전 정복

설치부터 첫 JSON 내보내기, 렌더러 호환성 함정까지 — 업계 표준 Lottie 파이프라인을 단계별로 따라갑니다.

TutorialAfter EffectsBodymovin 2026. 8. 1.·12분 읽기

준비물

필요한 것은 둘입니다: After Effects(Creative Cloud 구독)와 Bodymovin 확장. Bodymovin은 aescripts.com에서 name-your-own-price(0원 입력 가능)로 받는 무료 확장이고, 설치를 위해 무료 유틸리티 ZXP Installer(aescripts 제공)가 하나 더 필요합니다.

설치 — 5분 체크리스트

① aescripts.com/bodymovin에서 다운로드(zip 안의 .zxp 파일 확인) → ② ZXP Installer를 실행하고 .zxp를 드래그 → ③ AE 재시작 → ④ Edit(Win)/After Effects(Mac) → Preferences → Scripting & Expressions에서 "Allow Scripts to Write Files and Access Network"를 반드시 체크(빼먹으면 렌더 버튼이 조용히 실패합니다) → ⑤ Window → Extensions → Bodymovin으로 패널이 열리면 성공.

컴포지션 설정

새 컴포지션(Cmd/Ctrl+N)에서 권장 설정: 크기는 쓰일 곳 기준(아이콘 400×400, 히어로 800×600 등 — 벡터라 확대는 자유롭습니다), 프레임레이트 30fps(60은 파일만 커집니다), 길이는 2~5초. 배경은 투명하게 두고 배경색이 필요하면 셰이프로 직접 깝니다 — 컴프 배경색은 내보내기에 포함되지 않습니다.

셰이프 레이어로 그리기

Lottie의 기본 단위는 셰이프 레이어입니다. 툴바의 도형 도구(Q)로 캔버스에 그리면 자동으로 셰이프 레이어가 생깁니다. Illustrator 벡터를 쓰려면 .ai를 임포트한 뒤 레이어 우클릭 → Create → Create Shapes from Vector Layer로 변환하세요. 각 셰이프는 Contents 아래 Path + Fill/Stroke + Transform 구조인데, 이 구조가 그대로 JSON의 shapes 배열이 됩니다.

키프레임과 이징

레이어 선택 후 단축키로 속성을 열고(P 위치, S 스케일, R 회전, T 불투명도) 스톱워치 아이콘을 눌러 keyframe을 찍습니다. 기본 리니어 보간은 기계적으로 보이므로 keyframe 선택 후 F9(Easy Ease), 더 세밀하게는 그래프 에디터(타임라인 상단 그래프 아이콘)에서 속도 커브를 직접 조각합니다 — 오버슈트(살짝 넘었다가 돌아오는 탄성)는 커브를 목표값 너머로 그리면 됩니다.

실습 예제 — 로딩 스피너 만들기

배운 것을 하나로 묶는 최소 예제입니다. 목표: 호(arc)가 빙글 도는 로딩 스피너. 400×400 / 30fps / 2초 컴프에서:

단계조작값
1. 원 그리기Ellipse 도구, Fill 없음 / Stroke150×150, Stroke #FF6600, 두께 8, 캡 Round
2. 호 만들기셰이프 레이어 Add → Trim PathsStart 0%, End 30% (keyframe 없이 고정)
3. 회전R 키 → Rotation 스톱워치0프레임: 0° → 60프레임: 360° (1회전)
4. 루프 확인Space로 미리보기시작=끝 상태 동일 → 이음새 없음

이대로 Bodymovin으로 내보내면 아래와 동일한 결과가 나옵니다 — 이 데모는 위 표의 값 그대로를 Lottie JSON으로 옮긴 것입니다(뷰소스로 확인 가능):

▲ 결과물: Trim Paths 30% 호 + 360° 회전 (2초 루프)

Lottie 친화 기법 3종

Trim Paths(셰이프 레이어 Add 메뉴): Start/End를 애니메이션하면 선이 그려지는 효과 — 로고 드로잉의 핵심입니다. Repeater: 요소 복제 패턴도 지원됩니다. 마스크/매트: 알파 매트 기반 리빌 효과까지는 안전 범위입니다. 그리고 루프 설계 — 첫 프레임과 마지막 프레임의 모든 속성값을 일치시켜야 이음새 없이 반복됩니다.

피해야 할 것 (미지원 지뢰밭)

레이어 스타일, 대부분의 이펙트(Glow, Blur 일부 등), 3D 카메라·라이트, 일부 블렌드 모드는 렌더러가 무시하거나 깨집니다. 래스터 이미지는 기술적으로 가능하지만 base64로 JSON에 박혀 파일이 MB 단위로 커지니 벡터로만 구성하세요. 표현식(expressions)은 주의 대상입니다: lottie-web(웹)에서는 일부 동작하지만 iOS/Android 네이티브 렌더러와의 호환을 위해 keyframe으로 굽는 것(Animation → Keyframe Assistant → Convert Expressions to Keyframes)이 안전합니다. 전체 지원 매트릭스는 airbnb/lottie 저장소의 supported features 문서가 기준입니다.

Bodymovin으로 내보내기

Bodymovin 패널에서 내보낼 컴포지션 좌측 동그라미를 선택 → Destination 폴더 지정 → Settings(톱니)에서 옵션 확인: Glyphs(텍스트를 패스로 변환 — 폰트 없는 기기에서도 동일하게 보이므로 텍스트 쓰면 필수), Hidden(숨긴 레이어 제외), Standard/Demo(미리보기 html 동봉)/Standalone(js 포함) 중 Standard, 필요시 dotLottie/압축 옵션 → Render. 초록 완료 표시가 뜨면 .json이 생성된 것입니다.

▲ Bodymovin 패널 내보내기 4단계 흐름

검증과 트러블슈팅

내보낸 JSON을 LottieFiles 미리보기에 드롭해 웹 렌더링을 확인하고, 모바일 앱 대상이면 iOS/Android 렌더러에서도 확인하세요 — 렌더러 3종의 지원 범위가 서로 다른 것이 이 생태계 최대 함정입니다. 자주 겪는 문제: 패널이 안 보임 → 확장 설치/AE 버전 확인, Render가 조용히 실패 → 2단계의 스크립트 쓰기 권한 미체크, 특정 요소만 사라짐 → 미지원 기능 사용(7단계 목록 재점검).

웹에 올리기

완성된 JSON을 웹에 얹는 코드(lottie-web, 포스터, 재생/정지 접근성 컨트롤)는 "움직이는 이미지의 정체" 5장에 그대로 있습니다. 결과 파일만 갈아끼우면 됩니다.
